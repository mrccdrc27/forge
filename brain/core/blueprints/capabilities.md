# AI Feature: Core Execution Capabilities
**"The Muscle of the Sidecar"**

Forge provides specialized tools that turn high-level intent into technical reality.

## ⚡ Key Capabilities

### 1. Atomic Multi-File Expansion
Forge doesn't just write lines; it builds structures. 
*   **The Action:** Takes a "Skeleton Plan" and generates multiple related files (e.g., Controller + Service + Test) in a single operation.
*   **The Benefit:** Prevents "hallucination drift" and ensures all files in a feature are internally consistent.

### 2. Intelligent Project Scaffolding
*   **The Action:** One-click environment setup for standard stacks (React, Node, Python).
*   **The Benefit:** Initializes repositories, configures build tools, and sets up folder structures instantly.

### 3. Background Task Automation
*   **The Action:** Executes and monitors terminal tasks (install, build, test, lint) without blocking the IDE.
*   **The Benefit:** Keeps the developer and the Architect AI responsive while the "Contractor" handles the grunt work.

### 4. Code Modernization
*   **The Action:** Scans files for deprecated patterns and applies bulk updates (e.g., migrating from CommonJS to ESM).
*   **The Benefit:** Handles repetitive refactoring tasks that are too tedious for human developers but too "simple" for expensive reasoning models.

# 🧠 Forge Core Q&A: Knowledge Base
> **"The Brain (Bob) and The Body (Forge)"**

## ❓ Q: What is the core difference between Bob alone and Bob + Forge?
**A:** Bob is the **Chef** (The Brain/Strategy); Forge is the **Kitchen** (The Body/Execution).
- **Bob Alone:** Brilliant reasoning but trapped in "Chat Jail." He can suggest code but can't physically build complex, multi-file projects or run local shell commands without manual help.
- **Bob + Forge:** Forge gives Bob "Muscle." It provides direct hardware access (Bulk writes, Shell automation) and "Infinite Memory" (Filesystem watching). Bob directs the strategy; Forge handles the heavy lifting.

---

## ❓ Q: Why do we need Forge if Bob is already an all-around agent?
**A:** Specialization vs. Generalization. 
- **Resource Arbitrage:** Bob is "expensive" (high-reasoning tokens). Forge uses cheaper workers (Granite-8B) for "commodity coding" (boilerplate/scaffolding) to save your budget.
- **Context Depth:** Bob only knows what's in the chat. Forge watches your entire folder structure and feeds Bob the "Ground Truth" of your files instantly.
- **Automation Scale:** Bob can write one file well. Forge can scaffold 50 files and run `npm install` in one go.

## ❓ Q: How does the partnership work? (The Master/Slave Model)
**A:** Bob is the **Master Orchestrator**. Forge is the **Action Layer**.
1. **The Wallet (Sentry):** Forge checks the budget before Bob executes a plan.
2. **The Eyes (Ghost):** Forge watches the files and updates Bob on changes.
3. **The Muscle (MCP):** Bob uses the Forge "Remote Control" to perform physical tasks on the hard drive.

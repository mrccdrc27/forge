# AI Feature: Implementation Scopes
**"Where Forge Excels"**

Forge is optimized for "High-Velocity" domains where execution speed and structure matter most.

## ✅ High-Performance Scopes (Optimized)
Forge is pre-configured with templates and logic for:

### 🌐 Modern Web Applications
*   **Frameworks:** React (TypeScript/JSX), Vite, Tailwind CSS.
*   **State Management:** Zustand, Redux Toolkit, Context API.
*   **Build Tools:** Vite, Webpack, ESLint/Prettier.

### 🔌 Backend APIs & Services
*   **Node.js:** Express, Fastify, NestJS.
*   **Python:** FastAPI, Flask.
*   **Data:** MongoDB, PostgreSQL (Prisma/TypeORM).

### 🛠️ DevOps & Infrastructure
*   **Containerization:** Dockerfile generation, `docker-compose`.
*   **CI/CD:** GitHub Actions, GitLab CI.
*   **Local Dev:** Shell script automation, environment parity.

---

## ⚠️ Out-of-Scope (Bob-Only)
The following tasks are reserved for the **IBM Bob Architect** and should not be delegated to Forge:
*   **Strategic Architectural Decisions:** "Which database should we use?"
*   **Product Definition:** "What should the user experience be?"
*   **High-Level Logic Debugging:** "Why is this race condition happening in the auth flow?"
*   **Creative UI/UX Design:** Visual aesthetic and brand alignment.

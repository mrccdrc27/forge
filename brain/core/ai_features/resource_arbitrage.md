# AI Feature: Resource Arbitrage
**"The Economics of AI Development"**

Forge's primary mission is to minimize the cost of building complex software by routing tasks to the most efficient model possible.

## 💰 The Token Savings Model
Forge reduces "Development Overhead" by leveraging the cost difference between reasoning models and execution models.

*   **Reasoning Task:** (Architecture, Planning) → **Llama-3.3-70B** (Expensive).
*   **Execution Task:** (Boilerplate, Tests, Expansion) → **IBM Granite-8B** (Inexpensive).

**Result:** Building a feature with Forge typically reduces the total API budget impact by **60-80%**.

## 🛡️ Budget Guardrails
*   **Cost Prediction:** Forge analyzes Bob's implementation plan and estimates the "Bobcoin" or Token impact *before* a single file is written.
*   **Rate Limiting:** Protects against "Autonomous Loops" where a bug might cause an AI to burn through a budget in seconds.
*   **Transparent HUD:** The Forge Sidebar provides real-time visual feedback on current spend vs. saved budget.

## 🏢 IBM Ecosystem Integration
Forge is built to prioritize **IBM Granite** models via **watsonx.ai**. 
*   Granite-8B is treated as the "Primary Worker" for all commodity code tasks.
*   Ensures compliance with enterprise data privacy and performance standards.

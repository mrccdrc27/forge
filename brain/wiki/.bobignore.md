# .bobignore

The `.bobignore` file is used to control which files and directories [[IBM Bob Shell]] and [[IBM Bob IDE]] are allowed to access. It follows a similar syntax to `.gitignore`.

## Purpose
*   **Security:** Prevent the AI from reading sensitive files like `.env`, secrets, or private keys.
*   **Efficiency:** Exclude large directories (e.g., `node_modules`, `dist`, `.git`) to reduce context noise and token consumption.
*   **Focus:** Direct the AI's attention to relevant source code and documentation.

## Example Syntax
```ignore
# Exclude sensitive files
.env
secrets/
*.key

# Exclude build artifacts and dependencies
node_modules/
dist/
build/
package-lock.json

# Exclude git internals
.git/
```

## Best Practices
*   Always include `.env` and other credential-bearing files.
*   Exclude binary files and large datasets that the AI cannot meaningfully process.
*   Keep the `.bobignore` in the root of your project repository.

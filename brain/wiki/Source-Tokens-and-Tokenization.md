# Source: Tokens and Tokenization Docs

## Summary
Explanation of tokens and the tokenization process in [[IBM watsonx.ai]].

## Key Takeaways
- **Token Definition**: Semantic units for models (approx. 10 words = 15-20 tokens).
- **Context Window**: Upper limit of input + output tokens for a model.
- **Monitoring**: Token usage can be tracked in the project's Environments page.
- **API Access**: `Text tokenization` method available via API to pre-calculate counts.

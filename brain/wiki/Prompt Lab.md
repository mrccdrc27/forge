# Prompt Lab

The Prompt Lab is the primary interface in [[IBM watsonx.ai]] for experimenting with foundation models.

## Features
- **Modes**:
    - **Chat**: Conversational interface with system prompt support.
    - **Freeform**: Direct text entry for engineering prompts.
    - **Structured**: (Deprecated) Form-based prompt construction.
- **Grounding**: Support for document uploads and vector store integration.
- **Samples**: Library of pre-configured prompts for common tasks (classification, summarization, etc.).

## Workflow
1. Select a [[Foundation Models]].
2. Configure parameters (Max tokens, Stop sequences).
3. Enter prompt text and "Generate".
4. Save as a project asset for collaboration.

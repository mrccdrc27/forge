# IBM Bob IDE

IBM Bob is an intelligent software development partner designed to support teams throughout the journey from idea to solution.

## Account and Access
*   [Install Bob IDE](https://bob.ibm.com/docs/ide/getting-started/install)
*   [Create an IBMid](https://www.ibm.com/docs/en/storage-defender/base?topic=in-creating-ibmid)
*   [Access Bob Admin Portal](https://bob.ibm.com/admin/)
*   [Quickstart Guide](https://bob.ibm.com/docs/ide/getting-started/quickstart)

## Bobcoins (Usage Limits)
> [!WARNING] Limit
> Each team member gets **40 Bobcoins**. Once 100% usage is reached, no additional Bobcoins will be provided. Plan tasks to make full use of the team's combined allocation.
*   Monitor usage in the Bob admin portal or the IDE Settings > General tab.

## Key Features
*   **[Chat Interface](https://bob.ibm.com/docs/ide/features/chat-interface):** Interact using natural language.
*   **[Modes](https://bob.ibm.com/docs/ide/features/modes):** Specialized personas (Plan, Code, Advanced, Ask, Orchestrator).
*   **[Custom Modes](https://bob.ibm.com/docs/ide/configuration/custom-modes):** Can be global or project-specific.
*   **[MCP Servers](https://bob.ibm.com/docs/ide/configuration/mcp/mcp-in-bob):** Extend capabilities via Model Context Protocol.
*   **[Context Mentions](https://bob.ibm.com/docs/ide/features/context-mentions):** Use `@` to reference files, folders, and problems.
*   **[Security Guidelines](https://bob.ibm.com/docs/ide/security/bob-security-guidance):** Uses `.bobignore` to protect sensitive files.
*   **[Bob Tips](https://bob.ibm.com/docs/ide/features/bob-tips):** Real-time identification of quality issues.
*   **[Code Actions](https://bob.ibm.com/docs/ide/features/code-actions):** Quick fixes and AI suggestions.
*   **[Next Edit](https://bob.ibm.com/docs/ide/features/next-edit):** Code completions and automatic error fixes.
*   **[Slash Commands](https://bob.ibm.com/docs/ide/features/slash-commands):** Automate repetitive tasks with markdown files.
*   **[Checkpoints](https://bob.ibm.com/docs/ide/features/checkpoints):** Auto-versioning for non-destructive exploration.
*   **[Code Reviews](https://bob.ibm.com/docs/ide/features/code-reviews):** Review code before committing.
*   **[Commit Messages](https://bob.ibm.com/docs/ide/features/commit-messages) & [Pull Requests](https://bob.ibm.com/docs/ide/features/pull-requests):** Auto-generate metadata.
*   **[Literate Coding](https://bob.ibm.com/docs/ide/features/literate-coding):** Write instructions in comments.
*   **[Skills](https://bob.ibm.com/docs/ide/features/skills):** Reusable instruction sets (recipes).
*   **[Enhance Prompt](https://bob.ibm.com/docs/ide/features/enhance-prompt):** AI-powered prompt refinement.

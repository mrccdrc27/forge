# Source: Supported foundation models in watsonx.ai

## Summary
Inventory of third-party and IBM foundation models available in [[IBM watsonx.ai]].

## Key Takeaways
- **Model Providers**: IBM, Meta, Mistral AI, BigScience, Code Llama, DeepSeek AI, SDAIA, etc.
- **Model Gateway**: OpenAI-compatible API to route requests across multiple providers.
- **Deployment Methods**: Pay-per-token (multitenant) vs. Deploy-on-demand (dedicated).
- **Indemnification**: Only IBM-provided models accessed via watsonx.ai are indemnified.

# IBM Bob Dev Day Hackathon

This is the main entry point for the information regarding the IBM Bob Dev Day Hackathon.

## Core Components
*   **Theme:** "Turn idea into impact faster" using IBM Bob as an intelligent development partner.
*   **Required Technology:** [IBM Bob IDE](IBM%20Bob%20IDE.md) is mandatory and must be showcased as a core component.
*   **Optional Technologies:** [IBM watsonx Orchestrate](IBM%20watsonx%20Orchestrate.md) and [IBM watsonx.ai](IBM%20watsonx.ai.md), [IBM Bob Shell](IBM%20Bob%20Shell.md).
*   **Expectations:** Design and build a proof-of-concept solution. See [The Hackathon Expectation](The%20Hackathon%20Expectation.md).
*   **Examples:** Refer to [Hackathon Use Cases](Hackathon%20Use%20Cases.md).

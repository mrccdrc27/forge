# The Hackathon Expectation

## Theme: Turn idea into impact faster
Design and build a proof-of-concept solution using **[IBM Bob IDE](IBM%20Bob%20IDE.md)**. The solution should demonstrate how IBM Bob speeds up development, helps understand context, explains logic, and streamlines workflows.

## Judging Requirements
> [!IMPORTANT] Mandatory Deliverable
> Participants **must** export and upload their Bob IDE task session report in their code repository for judging purposes.
> [Learn how to export task session report](https://bob.ibm.com/docs/ide/features/history)
> 
> The reports must be placed in a folder named `bob_sessions` in the project submission code repository. This includes a screenshot of the task session consumption summary and the exported task history markdown file for all tasks related to the submission.

## Data Sets
Participants must bring their own data sets, adhering to these rules:
*   Data must be compliant.
*   Public website data is allowed if terms permit commercial use (keep a list of sites used).
*   **DO NOT USE:**
    *   Company confidential data without permission.
    *   Client data.
    *   Personal information (PI).
    *   Data obtained from social media.

## Other Technologies
You may use any framework/technology as long as it adheres to product usage policies, but [IBM Bob IDE](IBM%20Bob%20IDE.md) must be a core component. [IBM watsonx Orchestrate](IBM%20watsonx%20Orchestrate.md) and [IBM watsonx.ai](IBM%20watsonx.ai.md) are optional.

# IBM Bob Shell

Bob Shell brings IBM Bob's AI capabilities to the command line, optimized for shell environments and automated processes.

*   **Status:** Optional for the hackathon.
*   **[Install and Setup Bob Shell](https://bob.ibm.com/docs/shell/getting-started/install-and-setup)**
*   **[Authentication](https://bob.ibm.com/docs/shell/getting-started/install-and-setup)**: Requires an IBMid and browser authentication.
*   **[Start an Interactive Session](https://bob.ibm.com/docs/shell/getting-started/start-bobshell-interactive)**: Provides a conversational interface directly in the terminal.
*   **[Start a Non-interactive Session](https://bob.ibm.com/docs/shell/getting-started/start-bobshell-non-interactive)**: Use for automation, scripting, and batch processing.
*   **[Bob Shell Configuration](https://bob.ibm.com/docs/shell/configuration/configuring)**

# Model Gateway

The Model Gateway in [[IBM watsonx.ai]] provides a unified, OpenAI-compatible API for accessing various foundation models.

## Capabilities
- **Routing**: Securely routes requests to multiple third-party and IBM model providers.
- **Formatting**: Normalizes request/response formats across different providers.
- **Efficiency**: Allows developers to switch between providers without changing core integration code.

## Use Cases
- Building AI agents.
- Implementing [[Retrieval-Augmented Generation (RAG)]] patterns.

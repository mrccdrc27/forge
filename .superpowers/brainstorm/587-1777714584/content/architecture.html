Key Subsystem Mappings

  • Ghost Overlay: Lives in the Sidebar via ForgeSidebar.ts.
  • Context Engine: Uses native vscode.workspace.createFileSystemWatcher.
  • MCP Hub: Exposes local tools to IBM Bob via a tool bridge.

# Node.js Express API Setup

Welcome to your Express server! 🚂

## Prerequisites

- **Node.js**: v18.0.0 or higher.

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install express
   ```

2. **Run Server**:
   ```bash
   node index.js
   ```

## Structure

- `index.js`: Main entry point.
- `routes/`: API routes.
- `package.json`: Project metadata.

# Vue Vite Project Setup

Welcome to your Vue.js project! 🟢

## Prerequisites

- **Node.js**: v18.0.0 or higher.

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build**:
   ```bash
   npm run build
   ```

## Structure

- `src/`: Vue components and logic.
- `public/`: Static assets.
- `vite.config.js`: Vite configuration.

# Django Project Setup

Welcome to your Django project! 🐎🔋

## Prerequisites

- **Python**: v3.9 or higher.
- **pip**

## Getting Started

1. **Create Virtual Environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate # Windows: venv\Scripts\activate
   ```

2. **Install Django**:
   ```bash
   pip install django
   ```

3. **Start Project**:
   ```bash
   django-admin startproject myproject .
   ```

4. **Run Server**:
   ```bash
   python manage.py runserver
   ```

## Structure

- `manage.py`: Project management utility.
- `myproject/`: Settings and configuration.
- `apps/`: Your custom logic.

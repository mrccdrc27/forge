# Next.js Project Setup

Welcome to your Next.js application! 🚀

## Prerequisites

- **Node.js**: v18.17 or higher.

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Dev Server**:
   ```bash
   npm run dev
   ```

3. **Production Build**:
   ```bash
   npm run build
   ```

## Structure

- `app/`: App Router files.
- `public/`: Static assets.
- `next.config.js`: Next.js configuration.
